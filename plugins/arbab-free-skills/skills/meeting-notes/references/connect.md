# Set it up once (2 steps, about 2 minutes)

Skills are on every Claude plan, Free included, and need code execution switched on. Menus can move; if a name differs, look for the same words.

## 1. Add the skill
Claude on the web → **Customize → Skills** → upload `meeting-notes.zip` → switch it on.
(If asked, switch on **code execution** in the same settings.)

## 2. Make your meetings project
**Projects → New project** → name it <bdi dir="rtl">«محاضر الاجتماعات»</bdi> → switch the skill on inside it.
After each meeting, save the new `meeting-tasks.xlsx` into the same project so the next minutes know what's still open.

## Then, after every meeting
Drop the transcript (or the voice note's text, or your notes) and type:

<div dir="rtl" align="right">

‏سو لي محضر الاجتماع

</div>

## Where to get the meeting's text
- **Teams**: turn on Transcript during the meeting, then download it from the meeting chat.
- **Google Meet**: Transcripts (saved to your Drive).
- **Zoom**: Audio transcript in the cloud recording.
- **Phone call or in person**: record with iPhone Voice Memos (it shows the text) or any recorder app with transcripts.
- **WhatsApp voice note**: long-press it → Transcribe, then copy the text.

Claude writes the minutes; it never sends anything. You send the email and the WhatsApp message yourself.
