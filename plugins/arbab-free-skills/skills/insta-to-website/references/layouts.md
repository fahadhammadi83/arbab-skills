# Layout variation (on top of the style)

## Hero types
- **Full-bleed photo**: one strong photo fills the first screen, dark or light gradient for text. Use when they have one great wide or square photo (food, space, product hero). Crop so the subject sits away from the text.
- **Split**: text on the start side (right in Arabic), photo card on the other; stacks text-first on mobile. Use for clinics, services, teams.
- **Text-led**: huge headline/slogan, small photo or cut-out overlapping. Use when the brand is the person or the words (creators, consultants) or when photos are weak.

## Gallery types
- **Grid**: equal tiles 2 (mobile) / 3-4 (desktop). Clean; clinics, products.
- **Scroll strip**: horizontal snap-scroll row of tall tiles (9:16 covers, reels). Creators, cafés.
- **Masonry**: CSS columns, mixed heights. Food, fashion, interiors.

## Section order by business type
Always: hero → [type-specific first section] → rest → contact/location → footer. Omit any section with no data.

| Type | Order after hero |
|---|---|
| Clinic | Booking/contact card → services → team (if names visible) → gallery/cases → location |
| Restaurant / café | Menu (dishes or tasting menus seen in posts) → story (bio line) → gallery → recognition (only if they posted it) → visit/booking |
| Shop | Products → how to order (WhatsApp) → gallery → delivery/location |
| Consultant / creator | Proof (follower count, programmes, logos they show) → services → how it works → gallery of posts → contact |
| Salon / beauty | Services → gallery → team → booking |
| Real estate | Listings/projects → about → contact |

## Section catalog (pick, don't pad)
hero · booking card · services · menu · products · proof/stats (visible numbers only) · team · gallery · story/about · recognition (their own posts) · how it works · location + map · contact band · footer (handle, links, language toggle repeated).

## Never
- Testimonials unless they are real screenshots of reviews the user gave you (quote exactly, first name only).
- A pricing table unless prices are printed in the images.
- "Our numbers" with made-up stats.
