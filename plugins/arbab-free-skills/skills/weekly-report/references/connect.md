# Set it up once (3 steps, about 3 minutes)

Checked against Claude's Help Center on 14 Nov 2026: skills and the Microsoft 365, Gmail and Google Calendar connectors are available on every Claude plan, Free included. Skills need code execution switched on. Menus can move; if a name differs, look for the same words.

## 1. Add the skill
Claude on the web → **Customize → Skills** → upload `weekly-report.zip` → switch it on.
(If asked, switch on **code execution** in the same settings.)

## 2. Connect your work email and calendar
**Customize → Connectors** → find **Microsoft 365** (Outlook) or **Gmail** + **Google Calendar** → **Connect** → sign in with your work or personal account → allow.
A work account may need your IT team's approval the first time.

## 3. Make your report project
**Projects → New project** → name it <bdi dir="rtl">«تقريري الأسبوعي»</bdi> → add one old weekly report from your company (so it learns your format).
Each week, save the new `weekly-tracker.xlsx` into the same project.

## Then, every week
Open the project and type:

<div dir="rtl" align="right">

</div>

What Claude can and can't do with your email: it reads what the report needs, it never sends, replies, deletes or moves anything. You can disconnect any connector at any time from the same Connectors page.
